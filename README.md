A minimalist, local-first calendar application for scheduling that automatically rolls study slots over from week to week. It allows granular progress tracking across books, videos, and lessons with built-in **JSON** backup support.

The entire project was vibe-coded from scratch using **Gemini**. As such, it may contain bugs—if you find any, please file an issue.

I am not looking for new feature suggestions unless they are absolutely necessary from a productivity perspective. If you disagree or want to take it in a different direction, feel free to fork the project.

[The project site is here.](https://matriks404.github.io/study-block-planner/)
