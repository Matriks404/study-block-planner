A minimalist, local-first calendar application for scheduiling that automatically rolls study slots over from week to week. It allows granular progress tracking across books, videos, and lessons with built-in **JSON** backup support.

The entire project was vibe-coded from scratch using **Gemini**. So that said, it can contain bugs, if so fill an issue, please.

I don't want any new features suggestions aside from stuff that seem absolutely necessary from productivity perspective. If you disagree, fork the project.
